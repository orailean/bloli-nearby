# Find a Loo visual direction

User brief: distinctive and eye-catching, free icons, playful navigation, matching header/footer, no generic generated dashboard. Apply project-installed frontend-design guidance and review with web-design-guidelines.

- Palette: pool mint #ddf4e9, deep petrol #123f3b, paper white #ffffff, warm yellow #f3e76a, quiet sage #78918a. Use yellow for the character/primary emphasis, without gradient decoration.
- Type: self-hosted Bricolage Grotesque for the chunky wordmark/headings; DM Sans for controls/details. Comfortable body line lengths, sentence-case labels, Romanian glyphs.
- Layout: left-aligned punchy hero alongside one oversized toilet-roll character, followed by a single useful search workspace. A narrow results pane with divided rows sits beside the map on desktop; mobile puts an expandable results pane below the map. Header navigation and footer share the route/wayfinding motif.
- Motion: a short roll-and-settle entrance for the mascot; interaction-triggered squish on filters, pin wiggle on selection, brief sheet entry. Avoid a decorative animation on every element. Reduced-motion disables the movement.
- Distinctive element: a CSS toilet-roll character, with a paper tail pointing into the finder. Everything else stays useful and quieter. No filler stats, repeated decorative eyebrow labels, or generic gradient cards.
- UX guardrail: no joke delays, no playful obstruction of urgent search. Humor lives in supporting copy; labels state the action. Munich/81243 is the user's chosen search example.
