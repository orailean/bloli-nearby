## Rollback principles

- Back up the existing shared Nginx configuration before adding the new virtual host; validate with `docker exec nginx nginx -t` before every graceful reload.
- Do not restart or replace the shared Nginx or unrelated app containers.
- To remove the app route, move only `loo.bloli.com.conf` outside the `*.conf` include pattern, validate and reload Nginx.
- Keep the app database/import volumes and backups when stopping the app. Restore the project's database backup if needed.
- Existing Certbot timers and other domains' renewal settings remain unchanged; add a hook scoped to this app's certificate.
